Termux setup

          
    
            
  1. Install Termux from F-Droid (not the Play Store).
    2. 
            
  2. Run pkg update && pkg install nodejs git
    3. 
            
  3. Run git clone https://github.com/fffoxie/FreverS.git && cd FreverS && bash scripts/setup-termux.sh
    4. 
            
  4. Start npm start and keep Termux awake with termux-wake-lock.
    5. 
            
  5. Open this dashboard on the phone: http://127.0.0.1:8080/admin
    6. 
          

          
Install the patched APK

          
The patched APK has a different signature, so uninstall the original
            Frever first (this deletes its local data). Then install the downloaded
            FreverS-patched.apk. If Android blocks it, allow "install unknown apps"
            for your browser or file manager.

          
GitHub Pages

          
The same dashboard can be published from the web/ folder.
            Browsers block HTTPS pages from calling a plain-HTTP LAN address, so for full control
            open the dashboard served by the phone. From the phone itself,
            http://127.0.0.1:8080/admin is the reliable address.
