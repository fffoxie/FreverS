# FriendFactory Open Source Ecosystem Inventory

This document analyzes the open-source repositories published by **FriendFactory** (`https://github.com/FriendFactory`).

---

## 1. Core Services & Client Repositories

- [`frever-open`](https://github.com/FriendFactory/frever-open) – Main meta-repository and platform architecture overview.
- [`frever-open-unity-client`](https://github.com/FriendFactory/frever-open-unity-client) – Unity mobile application project (Unity 2022.3.28f1).
- [`frever-open-bridge`](https://github.com/FriendFactory/frever-open-bridge) – API Gateway service.
- [`frever-open-cms`](https://github.com/FriendFactory/frever-open-cms) – Content Management System.
- [`frever-open-backend`](https://github.com/FriendFactory/frever-open-backend) – Core backend microservices.
- [`frever-open-asset-manager-tool`](https://github.com/FriendFactory/frever-open-asset-manager-tool) – Asset processing and bundle management tooling.
- [`frever-open-shared-scripts`](https://github.com/FriendFactory/frever-open-shared-scripts) – Shared backend logic and schema definitions.
- [`frever-open-character-baking-tool`](https://github.com/FriendFactory/frever-open-character-baking-tool) – Avatar baking and mesh combiner processor.
- [`frever-open-wardrobe-preview-tool`](https://github.com/FriendFactory/frever-open-wardrobe-preview-tool) – Creator preview tool for clothing and accessories.
- [`frever-open-selfie-to-avatar-ml-server`](https://github.com/FriendFactory/frever-open-selfie-to-avatar-ml-server) – ML server for selfie-to-avatar generation.
